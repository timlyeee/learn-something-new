# 答题会话生命周期

> 状态：已完成

## 目标

课程卡片、AI 卡片与假名练习共用一个答题会话生命周期，保留现有版面、文案、评分、音效与交互。

## 设计

- `features/exercises/domain/ExerciseSession.ts` 管理当前题、一次作答、计分、错题、轮次及结束状态。题目与作答回显内容都是不透明数据，只读取题型提交的正确与否。
- 正式练习与错题复习明确区分；未作答不能推进，同题不能重复接受作答，结束后的推进不能重复产生正式成绩。错题复习不产生正式成绩；重新挑战建立新的正式轮次。
- `features/exercises/useExerciseSession.ts` 将生命周期连接 React、完成回调及正确音效。事件内同步更新会话，阻止连续事件重复计分或重复提交；React 只负责刷新展示。
- `QuizSession` 和 `KanaQuizSession` 是两种展示 adapter，负责题型判定与回显；共享 module 不解析答案字符串或假名题型。假名错题复习的步骤标题在展示时投影。
- 退出仍由现有页面卸载会话，不产生完成记录。音效偏好及存储格式不变。
- 空题组无法开始会话；无错题时发起错题复习保持当前状态。

## 验证

从答题会话 interface 验证未答阻止推进、重复作答、正确与错误计分、完成一次、错题轮次、重练复位、空题组和不透明题目/作答。执行类型检查、现有测试与生产构建；功能由用户验收。
