# 学习内容、闯关与进度

- 普通课程卡片在 `src/data/courses.json`（由 `src/lib/courses.ts` 的 `parseCourses` 解析为 `Course[]`）；词库在 `src/data/content.ts`；假名、路线和带罗马音词语在 `src/data/kana.ts`。既有 ID 保持稳定。
- 平假名和片假名分别学习、分别记录解锁。平假名为 7 个假名关和 1 个词语关，片假名为 12 个假名关和 1 个词语关。
- 假名普通关由脚本生成 5 个练习部分：读音选假名、假名选读音、动画提示手写、点击配对、词语应用；每部分 3 题，共 15 题。词语专项分为「罗马音选假名注音」与「假名注音选罗马音」两部分，各 5 题，答题后显示日常书写形式。课程与 AI 生成的卡片仍按卡片字段动态出题（释义题、读音题、例句选择题）。读音不等同于中文拼音；标注使用日语罗马音。
- 卡片（`Card`）是课程与练习的统一内容单元：`kind`（word/grammar/dialogue）+ 必填 `front`/`back`，可选 `reading`/`example`/`exampleMeaning`/`note`。题目由 `questionsFromCards` 按字段丰富度动态生成，字段多题就多、少题就少；干扰项从同批卡片字段抽取，保证 4 个不重复选项、唯一答案。
- 首页知识内容使用独立的 `KnowledgeCard` / `CardRevision` / `ContentBlock` 模型；现有 `Card` 只表示可复习的原子学习项，不得用它承载文章、视频、作者版本、用户笔记等发布内容。内置五十音以知识卡片和 `StudyDeck` 关系呈现，首页通过稳定游标逐批加载。
- AI 生成卡片：`cardPrompt(topic)` 要求输出严格 JSON 数组（5–8 张），`parseCards` 解析并校验，`/api/cards` 与 Android 原生直连复用同一条上游通路。生成的卡片可保存为卡片集（`SavedCardSet`），以 JSON 持久化到 localStorage 的 `learnnew-cards` 键，保存后本机可反复练习。
- 选择题必须有 4 个不重复选项和唯一答案，同音假名不能同时成为读音题的有效答案。手写题使用画布、动画轮廓提示和用户对照自评，当前不宣称具备 OCR 或笔顺识别；配对题使用点击两端完成，不以拖拽作为唯一操作方式。
- 正确率至少 80% 过关；80%、90%、100% 分别为 1、2、3 星。保存最高成绩；重练不降低成绩。错题复习不代替完整关卡成绩。
- 未检查答案时不能继续，同一题不能重复计分。退出未完成练习不记完成。
- 正确答案可播放短促成功音效，但声音不参与评分判断，也不得替代文字、图标与颜色反馈；用户关闭音效后所有题型遵循同一偏好。
- 进度沿用 localStorage 的 `learnnew` 键。新增字段必须迁移兼容旧备份，并在导入时验证结构。成绩和复习数据不能因 API 连接失败被清空。
- 本机网页、Android 和不同主机名之间存储独立；跨端迁移使用进度导出和导入。
- 当前教材仍是入门原型，不能宣称已有完整零基础到流利交流教材。
