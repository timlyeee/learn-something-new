# 界面设计系统

界面遵循「鲜亮艺术学习」风格：橙紫撞色、几何装饰、圆角卡片、统一矢量图标。本文件是视觉与交互的唯一规范；设计令牌以 `src/style.css` 的 `:root` 变量为代码真相源，两者冲突时以本文件为准。

## 设计基调

- 鲜亮撞色：电光紫负责导航、结构和完成状态，鲜橙负责主操作、当前步骤和能量强调，少量黄色与薄荷绿用于几何点缀。
- 艺术但可用：允许 Memphis 几何图形、非对称色块和轻量硬偏移阴影；正文、表单与测试答题面始终保持白色或极浅底色。
- 圆润有力：卡片保持 14–24px 圆角，结合 2px 深紫描边和 3–7px 偏移阴影，避免整页都是同一种柔和浮层。
- 不幼稚：每屏只保留一个主 CTA，高饱和颜色不承载长段正文，不用无意义动画堆叠装饰。

| ---------------------------------------------- | --------------------------------- | -------------------------- |
| `--primary`                                    | `#6D3AFF`                         | 导航、焦点、结构强调       |
| `--primary-strong`                             | `#5524D6`                         | 紫色 hover / 强调文字      |
| `--on-primary`                                 | `#FFFFFF`                         | 实色紫上的文字             |
| `--accent`                                     | `#FF6B2C`                         | 主按钮、当前步骤、高能强调 |

| `--bg`                                         | `#F1EDFF`                         | 页面背景（淡紫）           |
| `--surface`                                    | `#FFFFFF`                         | 阅读卡片与测试表面         |
| `--surface-2`                                  | `#F5F0FF`                         | 淡紫强调面板               |
| `--ink`                                        | `#24123D`                         | 主文字                     |
| `--ink-soft`                                   | `#3F2A5F`                         | 次要文字                   |
| `--muted`                                      | `#66577F`                         | 辅助文字（≥4.5:1）         |
| `--line`                                       | `#DED3F5`                         | 边框                       |
| `--line-strong`                                | `#C4AFE9`                         | 加粗边框                   |
| `--success` / `--success-ink` / `--success-bg` | `#16A34A` / `#166534` / `#E7F6EC` | 正确反馈                   |
| `--danger` / `--danger-ink` / `--danger-bg`    | `#DC2626` / `#991B1B` / `#FDEAEA` | 错误 / 破坏性操作          |

- 颜色不得硬编码进组件，一律使用语义令牌。
- 令牌采用 primitive → semantic → component 三层；组件状态优先引用组件令牌，语义令牌负责主题含义，原始色值只出现在 primitive 层。
- 正确/错误必须同时有图标或文字说明，不得单靠颜色传达。
- 深色模式尚未实现；令牌已预留，后续补齐时需单独验证对比度，不能直接反转现有值。

## 字体与排版

- 字体栈：`"Nunito", "PingFang SC", "Microsoft YaHei", "HarmonyOS Sans SC", "Hiragino Sans GB", "Noto Sans SC", sans-serif`。Nunito 由 `index.html` 以 `display=swap` 加载。
- Nunito 只覆盖拉丁字母与数字；中文/日文按系统字体回退，跨平台无法保证圆润属预期，不得为此引入体积过大的 CJK 字体包。
- 字号下限 12px，正文 15–16px；不再使用 9–11px 的正文或标签。
- 层级：h1 28–32px/800、h2 20–22px/700、h3 17–18px/700、正文 15px/500、辅助 13px。
- 行高 1.6–1.75；数字用 `font-variant-numeric: tabular-nums` 对齐。

## 形状、阴影与动效

- 圆角：卡片 18px、按钮 14px、胶囊 999px、小元素 10px。
- 阴影：常规表面使用柔和阴影；品牌卡片可使用 3–7px 深紫或橙色硬偏移阴影；主按钮保留厚底边与按压位移。
- 动效：过渡 150–250ms、ease-out；尊重 `prefers-reduced-motion`；状态切换显式设置终态，不依赖动画结束事件。

## 图标

- 统一使用 `@phosphor-icons/react`，线性风格（`weight="regular"`），默认 20px，随文字基线对齐。
- 品牌入口统一使用通用的 `Sparkle` 知识发现符号，不使用鸟居、富士山或其他把产品限定为某个国家、语言或学科的文化图标。
- 导航图标：首页 `House`、路线 `MapTrifold`、五十音「あ」、单词 `Stack`、对话 `ChatCircle`、设置 `Gear`。
- 五十音导航可以保留日文字符「あ」（非 emoji，语义最贴切），但仅作为日语模块内部入口，不作为应用品牌标识。
- 禁用 emoji 作为结构性图标；emoji 仅允许出现在用户内容与装饰性插画中，且不得承担导航或状态语义。

## 交互与无障碍

- 触控目标 ≥44px；按压反馈在 100ms 内；禁用态用 0.5 透明度 + 非交互语义区分。
- 可点击卡片、答案选项、配对按钮和常规按钮都要有下压位移、缩放或阴影收缩反馈；反馈不得引起相邻内容跳动，并在 `prefers-reduced-motion` 下取消非必要过渡。
- 答对音效只能作为视觉与文字反馈的补充；必须提供可发现的静音开关并保存本机偏好，音频不可用时不能阻塞计分或操作。
- 键盘焦点环可见（2px 主色、offset 2px）；表单有可见 label；错误就近说明并用 `aria-describedby` / `role="alert"` 关联。
- 每屏一个主 CTA，次要动作弱化；破坏性动作与常规操作分离。
- 首页知识卡片在手机端使用双列瀑布流：卡片按自身内容高度交错排列，不用固定等高填充；列间距不得小于 10px。双列状态下可以隐藏次要元信息，但标题、内容主体和学习入口仍需可读可点。

## 落地位置

- 令牌与基础布局：`src/style.css`；卡片与组件：`src/cards.css`。
- 新增组件复用现有类名与令牌，不在组件内写死颜色、字号或圆角。
